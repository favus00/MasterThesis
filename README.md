# Oil Price Pass-Through to Italian Retail Fuel Prices

Master's thesis project (Economics and Econometrics, University of Bologna).
Analyses how weekly Brent crude oil price shocks pass through to Italian
retail gasoline and diesel prices (2005–2024), with a focus on whether the
pass-through is **asymmetric** — i.e. whether retail prices react faster to
oil price increases than to decreases ("rockets and feathers").

## Methodology

1. **Descriptive statistics & stationarity** — all series are I(1) in levels,
   I(0) in first differences (ADF tests).
2. **Cointegration** — Engle-Granger two-step procedure confirms a stable
   long-run relationship between Brent and each retail fuel price.
3. **VECM** — short-run dynamics and error-correction speed of adjustment,
   estimated at 3 and 5 lags as a robustness check.
4. **Asymmetric models** — NARDL (Shin, Yu & Greenwood-Nimmo, 2014) and an
   Asymmetric ECM (Granger & Lee, 1989) decompose oil price changes (and, for
   the AECM, the equilibrium error) into positive/negative components to test
   for asymmetric pass-through.
5. **Markov-switching** — a 2-regime model (calm vs. turbulent oil market)
   tests whether transmission dynamics themselves change during crisis
   periods (2008 financial crisis, COVID-19, Russia-Ukraine war).
6. **Granger causality** — confirms the expected direction of causality
   (oil → retail prices) and checks for cross-fuel dynamics between gasoline
   and diesel.
7. **VAR / impulse response functions** — traces the full dynamic response of
   retail prices to a 1% Brent shock over a 20-week horizon.

## Repository structure

```
R/
  00_setup_data.R              # data import, cleaning, log transforms
  01_descriptive_stats.R       # summary stats, ACF/PACF
  02_stationarity_cointegration.R
  03_vecm.R                    # VECM, 3-lag and 5-lag
  04_asymmetric_models.R       # NARDL + Asymmetric ECM
  05_markov_switching.R        # 2-regime Markov-switching
  06_granger_causality.R
  07_forecasting_irf.R         # VAR + impulse response functions
  08_graphics.R
  run_all.R                    # runs the full pipeline in order
output/                        # LaTeX tables generated by the scripts
```

Scripts are numbered and meant to be run in order; each one assumes the
objects created by `00_setup_data.R` (and, where relevant, by
`02_stationarity_cointegration.R`) are already in the environment.

## Data

The underlying dataset (`Dati_completo.xlsx`: weekly retail gasoline/diesel
prices and Brent crude futures/spot prices, 2005–2024, sourced from LSEG
DataStream and ICE) is proprietary and not included in this repository. The
scripts document the exact transformations applied to it.

## Note on this repository

This is a cleaned, reorganized version of the original thesis code, written
originally as a set of separate exploratory scripts with substantial
duplication (each model was developed and run independently). Here the shared
data-preparation and estimation logic has been factored into reusable
functions (e.g. a single `run_vecm()` instead of two near-identical 3-lag and
5-lag scripts), and the whole pipeline is organized to be readable end to end
rather than as a collection of standalone snippets.
